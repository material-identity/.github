## Material Identity

Open schemas and tooling for digital material certificates.

Material certificates are still exchanged as PDFs that no system can read.
We publish open, versioned JSON schemas so that certificate data can be
validated, exchanged machine-to-machine, and rendered back into a
human-readable document when needed.

- **[schemas](https://github.com/material-identity/schemas)** — schema
  definitions for EN 10168, CoA, Metals and Forestry passports, plus a
  validation and PDF rendering service
- **[dictionary](https://github.com/material-identity/dictionary)** — public
  data dictionary for EN 18xxx digital product passports; every definition is
  an immutable entry at `https://material-identity.eu/def/<uuid>`

Older repositories (`CoA-schemas`, `EN10168-schemas`, `E-CoC-schemas`,
`schema-definitions`) are archived; their content now lives in `schemas`.
